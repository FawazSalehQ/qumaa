# Matching and extraction quality — 23 September 2026

The first engineering pass is implemented and verified in source. The original
drilling packet's proposed ranking gate **still fails** in both languages.
No human recruiter acceptance or Windows runtime result is claimed. September
22 installers do not contain these changes.

Subsequent [recall experiments and larger-model benchmarks](RECALL-2026-09-23.md)
retain this production baseline; the rejected alternatives did not provide a
consistent improvement.

## Changes and upgrade behavior

| Finding | Implemented change | Remaining limit |
| --- | --- | --- |
| D01: drilling vocabulary absent; generic Arabic emergency term classified as nursing | Added nine well-engineering concepts with English/Arabic aliases; replaced ambiguous clinical aliases with explicit clinical phrases. The dictionary now has 162 entries. | First domain coverage only; Arabic terminology and relevance labels need independent domain review. Mention detection does not establish ownership or competence. |
| D02: Arabic and Markdown section headings ignored | Conservative whole-line Arabic/English heading recognition, Markdown ATX/emphasis/Setext handling and source-offset checks. | Unrecognized compound headings still need investigation; arbitrary prose is deliberately not promoted to a heading. |
| D03: Arabic prose absent from lexical queries | Unicode words now reach SQLite FTS, with literal quoting, conservative stopwords and the existing 60-term cap. | This supplies Arabic lexical matching, not translation. Cross-language separation, prefix-budget coverage and top-three relevance remain open. |
| D04: experience text invented a Khobar address | Arabic token boundaries prevent `الخبرة` matching `الخبر`; genuine addresses and multiword locations remain recognized. | Location extraction remains heuristic. |
| Employment years consumed as month text | Narrow English month matching prevents a preceding job title swallowing a bare employment year range. | No broad date inference or unsupported dates were added. |

Parser-dependent fields, chunks and embeddings now carry a derivation version.
Startup preflights retained text before replacing caches, rebuilds before
opening search, and retries an interrupted rebuild on the next launch. CV IDs,
content hashes, original file paths, source text and manual recruiter records
remain unchanged. Existing saved match snapshots are removed because their
passage ordinals would otherwise refer to different text. Jobs request fresh
matching while retaining reviews, shortlist decisions and pipeline history.
Saved AI reranks belong to the discarded match cache and need an explicit new
rerank if desired; the upgrade makes no provider request.
Portable restore also records completed derivation provenance.

The model, query/passage prefixes, blend weights and section weights are
unchanged. No frozen labels, original pilot CVs or postings were altered.

## Independent paired-language check

A separate author created [six fictional careers in both languages](../eval/pilots/drilling-engineer/holdout-2026-09-23/README.md)
without inspecting production scoring/skills code, original pilot fixtures or
results. Labels and all 18 authored files were frozen before evaluation.
The manifest SHA-256 is
`3e745d29145dd852e9093798d0836770a66f33137236312bd790912932b9db61`;
it was verified before and after the runs. No source changes were made after
viewing these results.

Each run contains six distinct careers, three provisionally tier 1, using only
one language version per person. English files are H01/H04/H05/H07/H09/H10;
Arabic files are H02/H03/H06/H08/H11/H12. Exact copies and the corresponding label
subset were staged under ignored `eval/results/roadmap-2026-09-23/holdout-inputs`.
The current compiled evaluator ran sequentially with each frozen posting.

| CV language | Posting language | Strong candidates in top three | Tier-1 ranks | NDCG@10 | Preserved result |
| --- | --- | --- | --- | --- | --- |
| English | English | 3/3 | 1, 2, 3 | 1.0000 | [JSON](quality/2026-09-23/holdout-cv-en-jd-en.json) |
| English | Arabic | 3/3 | 1, 2, 3 | 1.0000 | [JSON](quality/2026-09-23/holdout-cv-en-jd-ar.json) |
| Arabic | English | 2/3 | 1, 2, 4 | 0.9909 | [JSON](quality/2026-09-23/holdout-cv-ar-jd-en.json) |
| Arabic | Arabic | 3/3 | 1, 2, 3 | 0.9960 | [JSON](quality/2026-09-23/holdout-cv-ar-jd-ar.json) |

All four runs imported six files without failures or duplicate warnings. No
tier-4 candidate entered a top three. Recall@10 is uninformative here because
each corpus has only six candidates. The proposed two-of-three condition holds
in this small controlled exercise, while the original mixed-language packet
still fails. These cleaner synthetic careers, provisional translations and
agent-authored labels do not establish human acceptance or mixed-language
ranking robustness. This packet is now a regression set; future tuning needs
another unseen evaluation.
