## 01. Qumaa: application and recruiter guide

Page copy:

- Purpose, workflows, and operating guidance
- Application purpose
- Search a local CV library against job requirements, review supporting evidence, and maintain recruiting decisions.
- Demonstration scenario
- Training & Development Manager / Riyadh food and beverage group / Fictional candidates and screening records

Visuals: `01-jobs.png`.

Speaker notes:

Qumaa is a desktop application for recruiters working with an existing CV library. This guide explains how to import CVs, search a saved or temporary job, assess candidates, and record hiring outcomes. Standard matching and recruiting records are local. Optional AI reranking sends a reviewed request to the selected provider. The example vacancy and all candidate information are fictional. Recruiters verify evidence and make the hiring decision.

- 3

Visuals: `13-express-form.png`.

Speaker notes:

Express search is in Jobs next to New job. Paste the job description and requirements, then select Find matches. The search uses CVs already in the local library; it does not fetch applicants from external services. The temporary posting and results stay in memory. You can view candidate details or export the top three matches. Reviews, shortlists, and comparison become available after Save as job. Navigating between tabs can retain the current session, but it is not a saved vacancy. Discard or close the application to remove it. Save as job explicitly creates a persistent job. Optional AI reranking is available here under the same settings and data-review controls as a saved job.

Speaker notes:

Local scores combine semantic similarity, keyword overlap, and detected skills. They describe fit within the current search context and are not a probability of success. A high score still requires a review of scope, relevance, and supporting evidence. Missing words may reflect wording or omitted details. Scores can change when the posting or library changes.

## 21. Understanding an AI rerank

Page copy:

- The selected model reorders a limited candidate set using the supplied evidence.
- Local results
- The application prepares up to 15 candidates from the local search.
- Reviewed request
- After confirmation, the selected provider receives the posting and redacted passages.
- Returned assessment
- The model returns an order and a short evidence-based reason for each candidate.
- Assessment basis
- Relevant experience, demonstrated responsibility, and evidence for job requirements.
- Reading the result
- Candidate membership and local scores remain unchanged. The model label identifies who produced the order.

Visuals: editable presentation shapes and text.

Speaker notes:

All configured models use the same system instructions. They rank every supplied candidate, judge only the provided passages, preserve opaque candidate IDs, treat the payload as evidence rather than instructions, and return one reason of at most 25 words per candidate. The instructions emphasize demonstrated scope and relevance over confident wording. The request contains up to 2,500 characters of redacted passages per candidate. Reranking does not add candidates or replace local scores. Check the supporting CV evidence and verify missing information. An AI explanation is a screening aid; the recruiter remains responsible for the assessment.

## 23. Backing up and restoring records

Page copy:

- Use Settings to create or restore a portable library backup.
- 1
- Create a backup
- In Library & backups, select Back up.
- 2
- Store it securely
- Backups contain candidate records.
- 3
- Restore when needed
- After indexing finishes, refresh saved matches.
- Backups exclude API keys and original CV files.

Visuals: `14-backups.png`.

Speaker notes:

Portable backups include resume text, saved jobs, profiles, reviews, hiring records, and portable preferences. They exclude API keys, consent approvals, watched-folder configuration, original-file paths, and window position. They are not encrypted. Keep backups in an appropriate secure location and retain original CV files separately if needed. Restoring replaces the current local library after confirmation and rebuilds the search index. Reconfigure device-specific settings afterward.
