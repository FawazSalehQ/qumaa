# قُمع: دليل مسؤول التوظيف بالعربية

[عرض PowerPoint](Qumaa_Recruiter_Guide_AR.pptx) · [نسخة PDF](Qumaa_Recruiter_Guide_AR.pdf) · [معاينة الشرائح](Qumaa_Recruiter_Guide_AR_Preview.png)

دليل عملي من ٢٤ شريحة لمسؤولي التوظيف، مع محتويات في الشريحة الثانية وملاحظات للمقدّم في كل شريحة. يتناول استيراد السير الذاتية، وإنشاء الوظائف المحفوظة، والبحث السريع، ومعايير التقييم، ومراجعة الأدلة، وملفات المرشحين، والمقارنة والقوائم المختصرة. ويشرح تحديث المطابقات، وسجل حالات الوظيفة، وتسجيل المرشح الذي تم تعيينه والبديلين رقم ٢ ورقم ٣، وإعادة الترتيب الاختيارية باستخدام Anthropic أو OpenAI، والنسخ الاحتياطي.

يحافظ الدليل على ترتيب النسخة الإنجليزية وهويتها البصرية. تقرأ الفقرات العربية من اليمين إلى اليسار، ويُعكس ترتيب بطاقات المحتويات ومخطط سير العمل بما يناسب العربية. النصوص والمخطط قابلان للتحرير في PowerPoint. يتضمن الدليل رابطًا قابلًا للنقر إلى صفحة Fawaz Aljathnan على LinkedIn.

## لقطات التطبيق

تعرض الصور في `screenshots/` واجهة قُمع العربية الفعلية من نسخة macOS المحلية الحالية، بالإصدار `v0.1.0-beta.2`. استُخدمت مكتبة مؤقتة وبيانات توضيحية خيالية لوظيفة مدير التدريب والتطوير لدى مجموعة مطاعم في الرياض. يسجل `screenshots/manifest.json` وقت الالتقاط ومصدر النسخة وأبعاد الصور.

يركّز كل ملف صورة على جزء محدد من الواجهة، بما في ذلك البحث السريع، وتغيير الحالة، وتسجيل التعيين، واختيار جهة الذكاء الاصطناعي ونموذجها، ومراجعة البيانات المُرسلة. يضم العرض اللقطات الأصلية دون إعادة رسم الواجهة. لم تُستخدم المكتبة الشخصية للمستخدم أو بيانات مرشحين حقيقيين.

## إعادة إنشاء العرض

من جذر المستودع، مع تثبيت Python 3 ومكتبتي `python-pptx` و`Pillow`:

```bash
python3 presentations/arabic/source/build_guide_ar.py
```

يعتمد البناء على القالب المشترك في `presentations/source/build_guide.py` وعلى `source/translations.json` واللقطات العربية. يفشل البناء عند غياب ترجمة أو صورة مطلوبة، أو إذا لم تكن المحتويات في الشريحة الثانية. يحفظ `source/storyboard-ar.md` النصوص وملاحظات المقدّم المطابقة للعرض النهائي، ويسجل `source/build-report.json` نتيجة البناء.

## إعادة التقاط الواجهة العربية

حدد الملف التنفيذي لنسخة قُمع الحالية، مع استخدام Node.js 22 أو أحدث وحزمة Playwright الموجودة في المستودع:

```bash
env -u ELECTRON_RUN_AS_NODE \
  QUMAA_GUIDE_EXECUTABLE="/path/to/قُمع.app/Contents/MacOS/قُمع" \
  node presentations/arabic/source/capture-guide-ar.cjs
```

ينشئ السكربت بيانات توضيحية مستقلة، ويحوّل لغة التطبيق إلى العربية، ثم يحذف المكتبة المؤقتة بعد إغلاق التطبيق. ترد تفاصيل أي تهيئة تجريبية لازمة لالتقاط إشعار مشاركة البيانات في بيان مصدر الصور.

## إنشاء PDF والمعاينة على macOS

باستخدام Quick Look وSwift وChrome وحزمة Playwright، اختر مجلدًا مؤقتًا جديدًا:

```bash
node presentations/arabic/source/render-guide-ar.cjs /private/tmp/qumaa-arabic-guide-preview-1
```

ينشئ السكربت صور الشرائح ونسخة PDF ومعاينة مجمعة وتقريرًا للتحقق من العرض. يحتفظ ملف PowerPoint النهائي بالنصوص والأشكال وملاحظات المقدّم القابلة للتعديل. نسخة PDF مخصصة للعرض والمشاركة؛ وتحافظ على تصميم الشرائح وروابطها القابلة للنقر.
